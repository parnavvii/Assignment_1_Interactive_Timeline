ASSIGNMENT 1 — INTERACTIVE TIMELINE WITH ARTIFACTS

Tool requirement:
This project specifically uses TimelineJS (Knight Lab), one of the timeline-creation tools listed in the assignment brief.

Files:
- index.html — the complete TimelineJS project
- style.css / script.js — optional earlier custom-design files retained as supporting files
- Assignment_1_Report.docx — documentation

How to run:
1. Open index.html in Chrome or Edge.
2. Keep internet enabled because TimelineJS, images and fonts are loaded from online sources.
3. Use the timeline arrows/drag controls.
4. Click each milestone to inspect its artifact and historical context.
5. Replace the team placeholder with your five names in the report before submission.

The timeline includes:
Bhimbetka, Dancing Girl, Lion Capital of Ashoka, Ajanta, Chola Nataraja, Mughal Miniature Painting, Madhubani and Warli.
